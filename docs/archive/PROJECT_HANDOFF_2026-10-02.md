## تصمیم‌ها و محدودیت‌های مهم

ریشهٔ مدل از فریم صفر Stand محاسبه می‌شود؛ استفاده از bind pose باعث معلق‌شدن مدل می‌شد. مدل برای جهت حرکت رسمی نیم‌دور می‌چرخد. هر شخصیت اسکلت و mixer مستقل دارد و مالکیت Canvas و کنترل با میزبان باقی می‌ماند.

بافت PNG از داخل GLB بدون تغییر بایت‌ها کنار مدل بسته‌بندی می‌شود و با TextureLoader بارگذاری می‌شود. مسیر blob داخلی در پروتکل دسکتاپ، شخصیت را بدون بافت نشان می‌داد. پلاگین از افزونهٔ عمومی GLTFLoader برای اتصال همان تصویر استفاده می‌کند. فایل GLB اصلی و نسخهٔ بسته‌شدهٔ آن تغییر نکرده‌اند.

ساخت renderer در R3F ۹.۶.۱ ممکن بود به‌دلیل بازنمایی UI هنگام init دو بار انجام شود؛ Promise مشترک برای هر Canvas از آن جلوگیری می‌کند. اعلام ready فقط پس از مشاهدهٔ پل واقعی تزریق‌شدهٔ الامر انجام می‌شود.

ظاهر پیش‌فرض آزمایشگاه، بافت اصلی بدون نورپردازی سطح است (`lighting="unlit"`). حالت `scene` نیز برای مقایسه وجود دارد و جنس اصلی را حفظ می‌کند، اما نور روی چهره و لباس ناهمگون دیده می‌شود. کیفیت این حالت حل‌شده نیست؛ تغییر فایل، بافت، هندسه یا انیمیشن اصلی برای پنهان‌کردن آن انجام نشده است.

پلاگین آواتار در میزبان با file dependency مصرف می‌شود و هنوز به Registry متصل یا منتشر نشده است. Player Rig رسمی با CLI نصب شده و فهرست plugins دستی تغییر نکرده است. هیچ test/publish شبکه‌ای، پیام به سازنده یا تغییر محیط اصلی انجام نشده است.

برای مرحلهٔ بعد، مسیر کد محیط اصلی یا همراهی سازندهٔ آن لازم است. اتصال محلی از `PlayerRig.avatar` و `onAnimationFrame` انجام می‌شود؛ کاربران دوردست از مسیر Fleet دیگری استفاده می‌کنند و صرف انتشار پلاگین آن‌ها را جایگزین نمی‌کند.
