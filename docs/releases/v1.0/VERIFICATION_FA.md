# راستی‌آزمایی مبنای نسخهٔ ۱٫۰

تاریخ اجرا: ۲۰۲۶/۱۰/۰۷، در checkout محلی پروژه.

## نتیجهٔ تازه

آزمون `npm test` در پوشهٔ آواتار: شش مورد موفق، صفر شکست، کد خروج صفر. آزمون `npm test` در avatar-lab: دو مورد موفق، صفر شکست، کد خروج صفر.

آزمون‌ها ارتفاع و محل پای مدل واقعی، استقلال skeleton و مواد نمونه‌ها، انتخاب کلیپ‌ها، fallback سقوط و فرود، پیش‌نمایش دستی و قرارداد عمومی Player Rig نصب‌شده را بررسی می‌کنند. دو هشدار `THREE.Texture: Unable to serialize Texture` در آزمون پلاگین دیده شدند؛ decoder تصویر آزمون Node جایگزین است. این نتیجه اثبات نمایش تازهٔ بافت در Desktop یا عملکرد VR نیست.

مدل اصلی با خواندن GLB بررسی شد: ۴۱ مفصل، نه کلیپ، ۲۸٬۹۶۱ رأس، ۹۳٬۴۳۲ index در primitive مثلثی، بدون morph target. در rig فقط زنجیره‌های نام‌گذاری‌شدهٔ شست و اشارهٔ هر دست وجود دارند؛ برای سه انگشت دیگر زنجیرهٔ مستقل وجود ندارد. هفت مفصل انتهایی، وزن مستقیم بالاتر از `1e-5` ندارند. دادهٔ کامل در `avatar03-rig-audit.json` است.

## حدود این نتیجه

کد، مدل، بافت، manifest و خروجی‌های اجرایی قبلی تغییر نکردند. build تازه یا پیش‌نمایش جدید در Desktop اجرا نشد، زیرا این مرحله طراحی نسخهٔ جدید و نگهداری مبنا است. هیچ رهگیری واقعی Quest، تغییر شکل با IK یا آزمایش چندکاربره انجام نشده است.

فهرست اولیهٔ قابل ثبت در Git پیش از شروع نسخهٔ ۲٫۰ با اندازه و SHA-256 ثبت شد. جست‌وجوی مقدماتی الگوهای شناخته‌شدهٔ credential در فایل‌های متنی انتخاب‌شده موردی پیدا نکرد؛ این جست‌وجو تضمین جامع امنیتی نیست. فایل‌های وضعیت نشست `.al-amr`، فایل‌های env، node_modules و کش ابزار با gitignore کنار گذاشته می‌شوند؛ مستندات نسخهٔ دقیق Player Rig حفظ می‌شوند.
