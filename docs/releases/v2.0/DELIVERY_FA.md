# تحویل Web V2 و محیط مقایسه — نسخهٔ فنی 0.1.1

هماهنگ‌شده در ۱۹ اکتبر ۲۰۲۶ با نتیجهٔ پذیرفته‌شدهٔ ۱۷ اکتبر. این پوشه یک تحویل محلی قابل انتقال است؛ candidate بارگذاری‌شدهٔ Registry نیست. نسخهٔ محصول دوم، نسخهٔ فنی Plugin `0.1.1` و قرارداد `1.0.0` جدا هستند.

## محتوا

- `آواتار/`: Plugin کامل با dist، مدل/حرکت منبع، کد، typeها، مجوزها و lockfile؛ ساخت آن به بیرون این پوشه وابسته نیست.
- `avatar-lab/`: منبع همان محیط مقایسهٔ V1 و V2، با Player Rig دقیق 1.0.0 و وابستگی `file:../آواتار`.
- `AVATAR_COMPARISON_TEST_FA.md` و `docs/tests/2026-10-17-avatar-comparison/`: گزارش و شواهد تصویری واقعی.
- `verification/`: شواهد آماده‌سازی قبلی و پذیرش مقایسه؛ تاریخ هر نتیجه محفوظ است.
- `release-metadata.json` و `release-inventory.json`: هویت، حدود آمادگی و هش فایل‌های تحویل.

منبع میزبان تک‌آواتار قبلی، پیش از هماهنگی، در workspace اصلی زیر `versions/avatar-lab-single-avatar-delivery-2026-10-17` نگه داشته شده است. آن پوشه snapshot کامل Plugin نیست.

## ساخت و اجرا

از ریشهٔ همین تحویل:

```powershell
npm --prefix './آواتار' ci
npm --prefix './avatar-lab' ci
npm --prefix './avatar-lab' run build
```

سپس با نصب الامر، `Open-Avatar-Lab.cmd` را اجرا کنید. پنجرهٔ Desktop هنگام بارگذاری نمایان باشد. خروجی تولیدشدهٔ Environment و node_modules در این کپی قابل انتقال نگهداری نمی‌شوند؛ build آن‌ها را می‌سازد. Plugin از قبل dist دارد و build میزبان همان Plugin را دوباره می‌سازد.

دکمهٔ تعویض/V بین دو آواتار، R بازگشت هر دو، H نمای فیلم و Esc بازگشت پنل است. کنترل‌های حرکت W/A/S/D، Shift، Space و F برقرارند. گزارش [مقایسه](../../../AVATAR_COMPARISON_TEST_FA.md)، [راهنمای میزبان](../../../avatar-lab/README.md) و [قرارداد Plugin](../../../آواتار/integration.md) مرجع جزئیات‌اند.

## ارسال در الامر

پوشهٔ انتخاب Plugin **`آواتار`** است؛ al-amr.plugin.json باید در سطح اول آن باشد. ریشهٔ تحویل یا avatar-lab را به‌جای Plugin انتخاب نکنید. UI خود الامر ساخت و بسته‌بندی را انجام می‌دهد؛ pack دستی لازم نیست. نسخهٔ 0.1.0 قبلاً ارسال/قفل شده بود؛ 0.1.1 یک بار برای نسخهٔ تازه انتخاب شد. برای Git push یا build دوباره bump نکنید.

بررسی قبلی بستهٔ Plugin سقف ۲۵ MiB و اعتبارسنج artifact را پاس کرد؛ فقط project-link در publish-doctor به ورود CLI نیاز داشت. نشست Desktop مستقل است. وضعیت زندهٔ حساب، مصرف نسخه و Registry در تحویل Git ۱۹ اکتبر استعلام یا تغییر داده نشده است. پیش از upload آینده آن‌ها را بررسی کنید؛ GitHub و Registry دو مسیر مستقل‌اند.

## اعتبار شواهد و حقوق

۲۳ آزمون Plugin و ۸ آزمون میزبان و اجرای واقعی مقایسه در ۱۷ اکتبر موفق بودند. مالک آن را کافی دانست؛ برای تحویل Git تست عملکردی تازه اجرا نشد. فایل `verification/comparison-acceptance.json` تاریخ شواهد و digest ساخت پذیرفته‌شده را ثبت می‌کند.

فایل `verification/portable-copy.json` فقط بازتولید مستقلِ میزبان تک‌آواتارِ پیش از مقایسه و ۲۵ آزمون آن مرحله را اثبات می‌کند؛ نتیجهٔ تازهٔ نصب مستقل میزبان مقایسه نیست. کپی فعلی با منبع پذیرفته‌شده و inventory تطبیق داده می‌شود.

node_modules، حساب، token و وضعیت محلی `.al-amr` در تحویل نیستند؛ فقط مستندات عمومی نسخهٔ دقیق Player Rig حفظ شده‌اند. commit کد `c557934` به avatar-v2 در GitHub ارسال و از سرور تطبیق داده شد. رسید در `verification/git-publication-2026-10-19.json` است؛ commit بعدی رسید و اسناد نهایی را نگه می‌دارد. inventory وضعیت فایل‌ها را ثبت می‌کند و جای رسید Git یا Registry نیست.
