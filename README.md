# پروژهٔ پلاگین آواتار الامر

این ریپوزیتوری کد پلاگین، محیط آزمایش، منابع اصلی آواتارها و مرجع تحویل نسخهٔ اول را نگهداری می‌کند.

## نسخهٔ ۱٫۰ — مبنای قابل بازیابی

نسخهٔ محصول ۱٫۰ همان مرحلهٔ قبلی با آواتار ۳ و کلیپ‌های آماده است. شمارهٔ فنی موجود در manifest و package.json برابر `0.1.0` است؛ نام نسخهٔ محصول، به معنی تغییر نسخهٔ ثبت‌شدهٔ Registry نیست.

مرجع Git این مرحله، برچسب `v1.0.0` است. شرح مبنا در [سند نسخهٔ اول](docs/releases/v1.0/BASELINE_FA.md) قرار دارد. فایل‌های اصلی، منابع چهار آواتار و خروجی مستقل محیط ۲ در تاریخچه حفظ می‌شوند.

## مسیر ورود به پروژه

- راهنمای شروع در [فایل شروع ایجنت بعدی](NEXT_AGENT_START_HERE.md) است.
- وضعیت واقعی و مرز ادامه در [گزارش تحویل](PROJECT_HANDOFF.md) ثبت می‌شود.
- کد پلاگین در پوشهٔ `آواتار` و قرارداد آن در `آواتار/integration.md` است.
- میزبان توسعه در پوشهٔ `avatar-lab` قرار دارد.
- مرجع محیط تحویل‌شده در پوشهٔ `AlAmr-Avatar03-Environment_2/محیط تست آواتار 2` است.

## بازیابی و اجرا

برای مشاهدهٔ مبنای تاریخی، برچسب `v1.0.0` را در یک checkout جداگانه باز کنید. پوشه‌های node_modules و ابزارهای محلی وارد Git نمی‌شوند؛ lockfileها، کد، منابع و خروجی‌های موجود حفظ می‌شوند. نصب وابستگی‌های Player Rig ممکن است به دسترسی Registry نیاز داشته باشد.

آزمون محلی با `npm test` در پلاگین و avatar-lab اجرا می‌شود. ساخت پلاگین با `npm run build` و سپس ساخت avatar-lab انجام می‌شود. قواعد `AGENTS.md` و skill الامر هر محصول را پیش از کار بخوانید. ساخت محیط ۲ فقط کاور را آماده می‌کند و صحنهٔ تازه نمی‌سازد.
