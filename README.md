# پلاگین آواتار الامر — Web V2

نسخهٔ فعلی، آواتار وب اصلاح‌شده و محیط مقایسهٔ آن با آواتار قبلی است. کفش و زانو، حرکت ورزشی، حالت‌های صورت و پلک V2 منتقل و بررسی شده‌اند. مشکل شفافیت بدن V1 نیز در نمونهٔ میزبان اصلاح شده است. مالک نتیجه را در ۱۷ اکتبر ۲۰۲۶ پذیرفت و در ۱۹ اکتبر ارسال همین نسخه به GitHub را خواست.

برای ادامهٔ کار از [راهنمای ایجنت بعدی](NEXT_AGENT_START_HERE.md)، [گزارش جاری](PROJECT_HANDOFF.md)، [روند پروژه](PROJECT_HISTORY_FA.md) و [نمایهٔ مستندات](DOCUMENTATION_INDEX_FA.md) شروع کنید.

## اجرا

با نصب الامر و خروجی موجود، [Open-Avatar-Lab.cmd](Open-Avatar-Lab.cmd) محیط را در Desktop باز می‌کند. هنگام بارگذاری پنجره نمایان باشد. برای build در clone تازه:

```powershell
npm --prefix './آواتار' ci
npm --prefix './avatar-lab' ci
npm --prefix './avatar-lab' run build
```

V بین دو آواتار جابه‌جا می‌شود؛ R هر دو را بازمی‌گرداند؛ H نمای فیلم را باز و Esc پنل را برمی‌گرداند. حرکت با W/A/S/D، دویدن با Shift، پرش با Space و پرواز با F است. راست‌کلیک همراه حرکت ماوس دوربین را می‌چرخاند. راهنما و تصویر واقعی در [گزارش مقایسه](AVATAR_COMPARISON_TEST_FA.md) است.

## وضعیت تحویل

۲۳ آزمون Plugin و ۸ آزمون میزبان و اجرای واقعی آخرین ساخت در ۱۷ اکتبر موفق‌اند. مالک تست بیشتر را لازم ندانست. این شواهد مربوط به همان تاریخ‌اند؛ برای ارسال Git، تست نمایشی تازه اجرا نمی‌شود.

نسخهٔ فعلی به شاخهٔ [avatar-v2 در GitHub](https://github.com/Ali-Tafakkor/Avatar_Plugin_AlAmr/tree/avatar-v2) ارسال شد. commit کد `c557934` با read-back سرور تأیید شده؛ [گزارش تحویل](PROJECT_HANDOFF.md) و [رسید Git](docs/releases/v2.0/git-handoff/git-publication-2026-10-19.json) مرجع‌اند. `main` و tag `v1.0.0` مرجع نسخهٔ اول باقی ماندند. Git push، انتشار Registry الامر نیست.

پوشهٔ انتخاب Plugin در الامر **`آواتار`** است؛ Environment نمونه جایگزین آن نیست. [گزارش آماده‌سازی](AVATAR_V2_RELEASE_PREPARATION_FA.md) و [راهنمای تحویل مستقل](releases/avatar-web-v2-0.1.1/README_FA.md) جزئیات را دارند. نسخهٔ محصول دوم، نسخهٔ فنی `0.1.1` و قرارداد `1.0.0` مفاهیم جدا هستند.

رهگیری واقعی Quest/WebXR، شبکه و جایگزینی آواتارهای دوردست هنوز پیاده‌سازی یا پذیرفته نشده‌اند. [طرح](AVATAR_V2_DESIGN_FA.md) و [نقشهٔ راه](AVATAR_V2_ROADMAP_FA.md) سابقهٔ تصمیم‌ها و کار آینده را نگه می‌دارند.
