# پلاگین آواتار الامر — آخرین نسخه Hybrid 0.1.3

**نسخهٔ اصلی فعلی در [پوشهٔ آواتار](آواتار/) است.** همین پوشه برای مصرف سایر پروژه‌ها و دکمهٔ ارسال نسخهٔ جدید در الامر انتخاب شود. رابط پیشنهادی **AvatarHybrid** است. [راهنمای آخرین نسخه](LATEST_AVATAR_FA.md) و [فایل مسیرهای ماشین‌خوان](LATEST_AVATAR.json) نقطهٔ شروع‌اند.

ظاهر نهایی در ۵ نوامبر ۲۰۲۶ پذیرفته شد: چهرهٔ ارتقایافته، دست‌های کامل و ریگ انگشتان، محافظ تماس، حالت خوش‌رو، لباس با پرداخت سبک، گردن اصلاح‌شده، idle آرام و یقهٔ نزدیک‌تر. گفتار میکروفن اختیاری است و منابع صوتی را میزبان تأمین می‌کند.

برای تست مرورگری از [Open-Avatar-Microphone-Test.cmd](Open-Avatar-Microphone-Test.cmd) و برای ساخت/پیش‌نمایش الامر از [Open-Avatar-Lab.cmd](Open-Avatar-Lab.cmd) استفاده کنید. تب منابع در محیط تست، پایش زنده و گزارش ده‌ثانیه‌ای دارد.

برای ساخت Plugin در پوشهٔ آواتار: `npm ci`، `npm run build` و `npm test`. فایل GLB قدیمی به‌تنهایی این آواتار نیست؛ بخشی از ظاهر و ریگ دست و idle توسط runtime اعمال می‌شود. دارایی‌ها و اصلاحات کامل با AvatarHybrid استفاده شوند.

منابع source، نسخه‌های versions و releaseهای 0.1.1/0.1.2 محفوظ و تاریخی‌اند. [روند پروژه](PROJECT_HISTORY_FA.md)، [تحویل پروژه](PROJECT_HANDOFF.md) و [نمایهٔ مستندات](DOCUMENTATION_INDEX_FA.md) سابقه و شواهد را نگه می‌دارند. GitHub و انتشار Registry دو وضعیت مستقل‌اند؛ ارسال نهایی در الامر با مالک است.
