using V1 only as a visual reference. These text snapshots preserve the final
direct-V1-transfer source and its geometric tests; they are evidence of an
abandoned experiment, not an accepted face or the active hybrid implementation.

The actual captures named `gate-*` and `gate2-*` are in the parent evidence folder.
The active replacement face uses `head-mount.mjs` and `sculpted-face.mjs`.
Source assets, the accepted product and Phase 1 are unchanged.
