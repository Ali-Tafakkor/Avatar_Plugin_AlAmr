# بایگانی میزبان تک‌آواتار پیش از مقایسه

منبع avatar-lab تحویل ۱۷ اکتبر، پیش از هماهنگی ۱۹ اکتبر، در زیرپوشهٔ avatar-lab حفظ شده است. این پوشه snapshot کامل Plugin نیست؛ metadata و inventory قبلی صرفاً سوابق تحویل آن تاریخ‌اند. برای بازگردانی، منبع میزبان را کنار Plugin سازگار قرار دهید و build کنید. محل جاری ادامه، avatar-lab ریشه است.
