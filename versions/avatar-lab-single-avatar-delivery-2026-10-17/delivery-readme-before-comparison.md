# تحویل Web V2 — نسخهٔ فنی 0.1.1

این پوشه خروجی مستقل آمادهٔ انتقال به Git است. نسخهٔ محصول «دوم» و نسخهٔ فنی Plugin در `package.json` و `al-amr.plugin.json` برابر `0.1.1` است. این نام‌ها به معنی وجود tag یا release منتشرشده نیستند.

## پوشه‌ها

- `آواتار/`: پلاگین کامل، همراه `dist` آماده، مدل/حرکت منبع، کد، typeها، مستندات، آزمون‌ها و lockfile. ساخت آن به فایل‌های بیرون این پوشه وابسته نیست.
- `avatar-lab/`: کد نمونهٔ مصرف‌کنندهٔ همین Plugin و قرارداد دقیق Player Rig 1.0.0. خروجی تولیدشدهٔ صحنه و node_modules در تحویل Git کپی نشده‌اند؛ build آن‌ها را می‌سازد.
- `verification/`: نتایج JSON آزمون‌ها، اعتبارسنج‌ها و برابری runtime با نسخهٔ بررسی‌شده.
- `release-metadata.json` و `release-inventory.json`: هویت نسخه، حدود آمادگی و اندازه/هش فایل‌ها.

## ارسال در الامر

پوشهٔ محصولی که باید توسط الامر ساخته و ارسال شود، **پوشهٔ `آواتار`** است؛ ریشهٔ کل تحویل یا `avatar-lab` را به‌جای Plugin انتخاب نکنید. فایل `al-amr.plugin.json` باید مستقیماً داخل پوشهٔ انتخاب‌شده باشد. در workspace اصلی، همان پوشهٔ ثبت‌شدهٔ `آواتار` نیز با این بایت‌ها به‌روز شده است.

نسخهٔ `0.1.0` قبلاً ارسال و قفل شده است. این تحویل هر دو نسخه را به `0.1.1` تغییر داده، هویت Plugin/ناشر/slug و `contractVersion` را حفظ کرده است. اگر UI هنوز `0.1.0` نشان می‌دهد، مسیر پوشهٔ محصول را بررسی و آن را بازخوانی کنید؛ هر بار شمارهٔ نسخه را بالا نبرید.

دکمهٔ «نسخه تازه را بفرست» Desktop ساخت و بسته‌بندی خودش را انجام می‌دهد. بستهٔ این تحویل از اعتبارسنج artifact رسمی و محدودیت ۲۵ MiB عبور کرده است. pack دستی، npm pack یا تغییر فایل‌های candidate قبلی لازم نیست. ارسال جدید هنوز به بازبینی انسان نیاز دارد؛ ارسال، انتشار نیست.

بررسی publish در CLI فقط به‌دلیل نیاز به احراز هویت CLI کامل نشده است؛ بررسی محلی بسته موفق است. نشست Desktop از ورود مستقل CLI جداست و دکمهٔ خود Desktop از نشست برنامه استفاده می‌کند. هیچ ورود، relink، upload یا ارسال برای بررسی توسط این آماده‌سازی انجام نشده است. دسترس‌بودن نهایی شمارهٔ 0.1.1 در تاریخچهٔ Registry بدون ورود CLI تأیید نشده است.

## ساخت از کد

داخل `آواتار`:

```powershell
npm ci
npm run build
npm test
```

داخل `avatar-lab`، پس از نصب وابستگی‌های Plugin:

```powershell
npm ci
npm run build
npm test
```

مثال با وابستگی `file:../آواتار` همین بسته را مصرف می‌کند. این آزمایش محلی اثبات نصب release منتشرشده در Registry نیست. API توصیه‌شدهٔ نسخهٔ تازه `AvatarWebV2` است؛ رابط قدیمی `Avatar03` نیز برای سازگاری حفظ شده است. اتصال کامل در README و integration.md پلاگین آمده است.

## انتقال به Git و حقوق دارایی‌ها

node_modules، فایل حساب، token و وضعیت محلی `.al-amr` در این تحویل نیستند؛ فقط مستندات عمومی نسخهٔ دقیق Player Rig حفظ شده‌اند. این پوشه Git مستقل یا commit ندارد و به سرور ارسال نشده است. فهرست هش برای مقایسهٔ کپی‌هاست و candidate منجمد Registry نیست.

مجوز MIT مربوط به کد برنامه/adapter است. مدل، بافت و motion حقوق جدا دارند. منبع AvatarSDK این فایل را برای استفادهٔ غیرتجاری معرفی می‌کند؛ `LICENSE` و `THIRD_PARTY_NOTICES.md` را پیش از عمومی‌کردن Git یا توزیع Registry بخوانید. این آماده‌سازی، حق تجاری یا اجازهٔ مستقل بازتوزیع عمومی برای دارایی‌ها ایجاد نمی‌کند.

مشاهدهٔ تصویری قبلی به درخواست مالک کافی پذیرفته شد. ۲۳ آزمون روی ماژول‌های ساخته‌شدهٔ Plugin و دو آزمون میزبان، ساخت TypeScript/Vite و اعتبارسنج محلی انجام شده‌اند؛ این تحویل اجرای تازهٔ Desktop، رهگیری واقعی VR یا انتشار نهایی را ادعا نمی‌کند.

کپی مستقل دیگری از همین تحویل با `npm ci --offline --ignore-scripts` نصب و ساخته شد؛ همان ۲۵ آزمون در آن موفق بودند. ۴۱ فایل dist بازتولیدشده با تحویل یکسان‌اند. نتیجه در `verification/portable-copy.json` ثبت شده است.
