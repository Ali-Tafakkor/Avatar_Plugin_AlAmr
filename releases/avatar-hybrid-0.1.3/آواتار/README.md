# آواتار ۳ — Hybrid 0.1.3

این پوشه نسخهٔ اصلی و آمادهٔ انتخاب در دکمهٔ ارسال الامر است؛ ظاهر نهایی در ۵ نوامبر ۲۰۲۶ توسط مالک پذیرفته شد. manifest و package و lock نسخهٔ **0.1.3** دارند. محصول، ناشر و slug قبلی حفظ شده‌اند.

رابط پیشنهادی **AvatarHybrid** است: چهره و بافت ارتقایافته، ۶۶ کانال صورت، شش احساس و پلک/نگاه، دست‌های کامل با ریگ انگشتان، حالت طبیعی، محافظ تماس دست، لباس با پرداخت سبک، گردن اصلاح‌شده، idle آرام و یقهٔ نزدیک‌تر. برای این ظاهر از پکیج/runtime کامل استفاده کنید؛ GLB قدیمی به‌تنهایی این اصلاحات را ندارد. Avatar03 و AvatarWebV2 برای سازگاری قبلی حفظ شده‌اند.

## استفاده و ساخت

قرارداد، نمونهٔ اتصال، منابع دارایی‌ها و کنترل دست‌ها در [integration.md](integration.md) است. میزبان مالک Canvas، WebGPURenderer، کنترلر و navigation است. React 19، Three 0.185.1 و Fiber 9.6.1 مبنا هستند. برای کپی منابع محلی، `avatar-lab/scripts/prepare-avatar-hybrid.mjs` در مخزن را ببینید؛ تصاویر و bufferهای glTF و face-albedo باید همراه مدل بمانند.

```powershell
npm ci
npm run build
npm test
```

آزمون‌های مقایسه با سابقه در مخزن کامل اجرا می‌شوند؛ کپی مستقل تحویل، آزمون‌های محلی مناسب خودش را دارد. داده‌های هندسه/ریگ/morph/انیمیشن و تصاویر دقیقاً حفظ شده‌اند؛ فقط تصاویر تکراری داخل بافر هنگام بسته‌بندی حذف می‌شوند. مدل‌های اصلی در assets-source محفوظ‌اند.

## گفتار اختیاری

گفتار میکروفن و خندهٔ شنیداری در [SPEECH_INTEGRATION.md](SPEECH_INTEGRATION.md) توضیح داده شده‌اند. فایل‌های مدل صوتی و ONNX/WASM را میزبان تأمین می‌کند و مجوز میکروفن با کاربر است. نمایش و احساسات دستی به مدل صوتی نیاز ندارند. capture یا آزمون مصنوعی، طبیعی‌بودن lip-sync واقعی را اثبات نمی‌کند.

## ارسال در الامر

همین پوشهٔ **آواتار** را انتخاب کنید؛ نسخه باید **0.1.3** نشان داده شود. ارسال و انتشار نهایی با مالک است. `alamr test` آپلود candidate است، نه آزمون محلی. آزادبودن آنلاین نسخه در CLI به ورود نیاز دارد و تأیید نشده است. build یا retry به‌تنهایی نیاز به افزایش شماره ندارد.
