# تحویل مستقل آواتار Hybrid 0.1.3

پوشهٔ آواتار همین کیت همان Plugin اصلی ریشه است و برای نصب محلی یا انتخاب در دکمهٔ ارسال الامر آماده شده است. راهنمای اتصال داخل آواتار/integration.md است. در پوشهٔ آواتار، npm ci و npm run build اجرا شود. npm test فقط آزمون‌های مستقل این کیت را اجرا می‌کند؛ دو آزمون وابسته به مقایسهٔ تاریخی در مخزن اصلی محفوظ‌اند.

ظاهر ۵ نوامبر پذیرفته شده است. مدل قدیمی به‌تنهایی جای runtime کامل را نمی‌گیرد. فایل‌های اختیاری مدل گفتار/WASM متعلق به میزبان و خارج از Plugin هستند. Registry هنوز توسط عامل آپلود یا منتشر نشده است؛ آزادبودن آنلاین 0.1.3 تأیید نشده است.
