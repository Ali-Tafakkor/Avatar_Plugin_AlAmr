# محیط مقایسهٔ آواتارهای الامر

این همان Environment تست قبلی است؛ هر دو مدل V1 و Web V2 را در یک صحنه نمایش می‌دهد. Plugin محلی `../آواتار` و Player Rig رسمی و دقیق `1.0.0` مصرف می‌شوند. نسخهٔ میزبان `0.1.0` است و با نسخهٔ Plugin `0.1.1` فرق دارد.

## اجرا و کنترل

از ریشه `Open-Avatar-Lab.cmd` را اجرا کنید. برای clone تازه ابتدا وابستگی‌های Plugin و سپس این میزبان را با `npm ci` نصب کنید؛ `npm run build` در این پوشه هر دو را می‌سازد. مسیر CLI دقیق در AGENTS.md است. خود الامر باید نصب و پنجره‌اش هنگام بارگذاری نمایان باشد.

- «تعویض آواتار» یا V: تغییر نسخهٔ تحت کنترل، با حفظ هر دو نمونه.
- «نمای هر دو»، «دنبال‌کننده»، «صورت» و «پا و زانو»: دوربین‌های بررسی.
- W/A/S/D، Shift، Space، F و Ctrl: حرکت، دویدن، پرش، پرواز و پایین‌آمدن در پرواز.
- «بازگشت هر دو» یا R: قرارگرفتن دوبارهٔ مدل‌ها در دو جایگاه جدا.
- «نمای فیلم» یا H: پنهان‌کردن پنل؛ Esc آن را برمی‌گرداند. ضبط و ارسال ویدیو خودکار نیست.

فقط یک PlayerRig ورودی و دوربین را مدیریت می‌کند. دو controller، موقعیت مستقل دارند؛ تغییر انتخاب، مدل‌ها را بارگذاری مجدد نمی‌کند. هنگام تعویض، ورودی قبلی آزاد و مدل قبلی روی زمین پارک می‌شود. سرعت اصلی V1 برابر ۵/۹ و پروفایل V2 برابر ۲٫۲۵/۶٫۲ متر بر ثانیه است.

## کد و دارایی

`src/CompareApp.tsx` صحنهٔ مشترک، `comparison.mjs` مالکیت کنترل و `LegacyComparisonAvatar.tsx` همراه `legacy-preview.mjs` اصلاح متریال V1 را پیاده می‌کنند. اصلاح شفافیت/depth write فقط روی متریال clone نمونه انجام می‌شود؛ فایل مدل و نه کلیپ قدیمی تغییر نکرده‌اند. `AvatarWebV2.tsx` export واقعی Plugin را مصرف می‌کند.

`src/main.tsx` به‌طور پیش‌فرض مقایسه را باز می‌کند. کد تست تک‌آواتار قبلی در همان فایل و مسیر `?mode=single` حفظ شده است. `scripts/prepare-avatar-v2.mjs` glTF، buffer، motion و تصاویر را از dist خود Plugin کپی می‌کند؛ ساخت به AvatarRuntime یا cache ورودی مالک وابسته نیست. بازکردن دستی avatar.bin لازم نیست.

## شواهد و ادامه

در ۱۷ اکتبر ۲۰۲۶، ۸ آزمون میزبان و ۲۳ آزمون Plugin، build و بررسی رسمی پروژه موفق بودند. تعویض دوطرفه، حرکت واقعی مستقل و تصویر اصلاح‌شده در الامر بررسی شدند. مالک گفت تست کافی است؛ این تأیید برای تحویل Git تکرار نمی‌شود. تاریخ و شواهد در [گزارش مقایسه](../AVATAR_COMPARISON_TEST_FA.md) ثبت‌اند.

منابع چهار آواتار و محیط تحویل‌شده را حفظ کنید. مدیریت فهرست plugins با ابزار رسمی الامر است. `alamr dev` پیش‌نمایش محلی و `alamr test` بارگذاری candidate انتشار است؛ این دو را جایگزین هم نکنید. ثبت GitHub مجوز ارسال Registry نمی‌دهد. پیش از تغییر، AGENTS.md، skill محصول و مستندات دقیق `.al-amr/docs/plugins` را بخوانید.
