# پلاگین آواتار ۳

این پلاگین مدل آمادهٔ آواتار ۳ را با ۹ انیمیشن داخل فایل GLB در اختیار محیط‌های سه‌بعدی الامر قرار می‌دهد. نمایش‌دهندهٔ شخصیت به ورودی عمومی `PlayerRig.avatar` متصل می‌شود و از `onAnimationFrame` وضعیت حرکت را دریافت می‌کند. زمین، جابه‌جایی بازیکن، دوربین و شبکه متعلق به محیط میزبان هستند.

## وضعیت نسخهٔ محلی

نسخهٔ ۰.۱.۰ برای ساخت و پیش‌نمایش محلی است. شناسه و ناشر اولیه هنوز به یک انتشار Registry متصل نیستند. نمونهٔ مستقل مصرف‌کننده در پوشهٔ `../avatar-lab` قرار دارد؛ وابستگی محلی آن با مسیر `file:../آواتار` وارد build می‌شود. این روش اثبات نصب یک انتشار در Registry نیست.

## سازگاری و اتصال

میزبان: محیط وب با React نسخهٔ ۱۹، Three نسخهٔ ۰.۱۸۵.۱ و React Three Fiber نسخهٔ ۹.۶.۱. محیط آزمایش از Player Rig رسمی نسخهٔ ۱.۰.۰ و `WebGPURenderer` استفاده می‌کند. قرارداد کامل در `integration.md` و تعریف نوع‌ها در `dist/index.d.ts` است.

نمونهٔ اتصال در کد محیط، داخل Canvas موجود:

```tsx
const avatar = useRef<Avatar03Handle>(null);
return <Suspense fallback={null}>
  <PlayerRig controller={controller} navigation={navigation}
    avatar={<Avatar03 ref={avatar} modelUrl={modelUrl} />}
    onAnimationFrame={motion => avatar.current?.setLocomotion(motion)} />
</Suspense>;
```

نمونهٔ کامل و قابل اجرا با importهای واقعی در `../avatar-lab/src/main.tsx` قرار دارد. نام بستهٔ محلی `@al-amr-community/usr-20dfea67-47be-4f4a-b48c-02c5f210a079--avatar03` است و پس از اتصال به Registry نام بررسی‌شدهٔ ناشر جایگزین می‌شود. ابزار Vite فایل را با export مدل و `?url` بسته‌بندی می‌کند؛ سایر ابزارهای ساخت باید URL مدل محلی را به `modelUrl` بدهند.

## انیمیشن‌ها

تطبیق خودکار: ایستادن با `Stand`، راه‌رفتن با `Walk`، دویدن با `Run`، پرش با `Jump` و پرواز با `Fly`. حالت سقوط از ادامهٔ کلیپ پرش استفاده می‌کند و فرود به ایستادن برمی‌گردد؛ این دو انیمیشن اختصاصی جدید نیستند. وضعیت `fallback` در API این حالت را مشخص می‌کند.

بررسی دستی با `previewClip` برای هر ۹ کلیپ ممکن است. آرگومان `null` کنترل را به حرکت میزبان برمی‌گرداند. نشست‌وبرخاست و بالا بردن دست فعلاً به فرمان‌های جدید محیط متصل نشده‌اند.

## منابع و چرخهٔ عمر

مدل اصلی تغییر نمی‌کند و build هش SHA-256 آن را بررسی می‌کند. اندازهٔ پیش‌فرض ۱.۷۸ متر و ریشهٔ نمایش روی کف است. هر نمونه اسکلت و mixer مستقل دارد. هنگام unmount، mixer، materialهای اختصاصی و منابع اسکلت آزاد می‌شوند؛ هندسه و تکسچر مشترک در cache مدل باقی می‌مانند. میزبان Canvas، Suspense، خطای بارگذاری و پایان عمر نمونه را مدیریت می‌کند.

بافت PNG درون GLB نیز بدون تغییر بایت‌ها در خروجی قرار می‌گیرد تا از مسیر محلی قابل‌استفاده در الامر بارگذاری شود. پیش‌فرض `textureUrl` کنار ماژول است؛ ابزار ساخت میزبان باید آن را همراه فایل مدل بسته‌بندی کند. جهت پیش‌فرض مدل با محور منفی Z کنترلر رسمی هماهنگ است.

ویژگی `lighting` دو حالت دارد: مقدار `scene` جنس اصلی و نور صحنه را حفظ می‌کند؛ مقدار `unlit` فقط بافت اصلی را نشان می‌دهد. آزمایشگاه برای نمایش اولیه از `unlit` استفاده می‌کند، چون حالت نورپردازی صحنه فعلاً ناهمگونی قابل مشاهده دارد. این محدودیت به‌عنوان اصلاح کیفیت مدل، حل‌شده گزارش نمی‌شود.

پلاگین مجوز پلتفرمی، backend، شناسهٔ حساب یا ارسال داده ندارد و فایل مدل بسته‌شده را بارگذاری می‌کند. مجوز دارایی‌های تأمین‌شده توسط مالک پروژه مستقل از مجوز کد پلاگین است.

## ساخت و بررسی

دستورهای محلی: `npm ci`، سپس `npm run build` و `npm test`. ابزار رسمی الامر با مسیر ثبت‌شده در `AGENTS.md` اجرا شود: `alamr validate --json` و `alamr doctor --profile project --json`.

برای آزمایش داخل الامر، راهنمای محیط آزمایش را بخوانید. این نسخه مسیر نمایش گروهی کاربران دوردست را جایگزین نمی‌کند؛ اتصال به Fleet میزبان به ادغام و بررسی عملکرد جداگانه نیاز دارد.
