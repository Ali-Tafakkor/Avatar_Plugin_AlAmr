List reference files and what each view establishes. Mark which photo is authoritative when views disagree. Ask about the outfit when it is unspecified or ambiguous, and record whether to follow the photos, a written choice or a delegated design. Add only the questions needed to proceed.

Choose a rigged base asset or author one. Record provenance and which features will be changed through geometry, texture or material. Identify a comparison pose, view and lighting setup for review. Mark the likeness and outfit approved only after the user reviews the rendered character or cites an already accepted reference.
