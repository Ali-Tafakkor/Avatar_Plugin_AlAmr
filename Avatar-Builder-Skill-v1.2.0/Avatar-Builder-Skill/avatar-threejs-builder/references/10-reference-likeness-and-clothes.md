# 10 — Likeness and clothing from reference images

## Resolve the visual brief

Use the [appearance brief](../assets/APPEARANCE-BRIEF.template.md). Inspect the actual images and label each by view, pose, framing, lighting and what it can establish. Compare frontal and side photos before using the silhouette, then three-quarter and full-body views for proportion, hairstyle, clothing fit and footwear. A face close-up helps place landmarks but perspective, smile and lighting can distort width, jawline and skin tone. A full-body photo without a scale reference establishes ratios and silhouette more reliably than height. Ask for a missing angle only when it would materially affect the requested likeness. If it is unavailable, document the interpretation of the unseen part and show it early.

Record high-salience likeness cues: head silhouette, eye spacing and lid shape, brow line, nose projection, mouth and chin, hairline, hair silhouette, skin undertone, distinctive marks and body proportions. Use the user's explicit choices for stylization and changes. Treat text and photo details as inputs to inspect, with permission to use the references in the intended delivery. Check before sending private photos to a third-party service. Keep reference photos outside distributed runtime assets unless intended for delivery.

If no outfit is clear, ask one focused question, for example “What outfit and shoes should the avatar wear? I can follow the photos if you prefer.” If color, fit, fabric, neckline or layers materially affect the result and the user has not specified or delegated them, resolve those details as well. Keep rig setup and source inspection moving while the outfit is pending. A face reference by itself supplies no outfit choice. A clearly designated full-body outfit reference can supply it without another question.

## Turn the brief into actual 3D assets

1. Inspect the selected base mesh using [asset and authoring guidance](02-assets-and-authoring.md). Start with compatible topology, working facial deformation and a skinned body. Pick a relatively neutral pose for comparing geometry. If only photos are provided, use an available authoring tool or authorized 3D source to create/adapt a real model. A generated portrait can serve as a visual reference.
2. Assign each change to a representation. Adjust silhouette, cheek/jaw/nose profile, hair volume, garment cut and prominent features in geometry. Paint skin tone, markings and cloth color on the albedo in the model's UV layout. Set surface response in materials. Avoid baking photo highlights, harsh shadows or perspective into the albedo. Apply masks consistently across body, face and hands.
3. For repainting, export the existing UV atlas and label eyes, lips, brows, hairline and seams. If using an image-editing tool, give it the existing atlas and approved references. Ask it to preserve island positions, gutters and landmarks. Verify the result on the actual model from front, profile and three-quarter views. An image-editing prompt cannot enforce vertex-level alignment. Adjust or repaint misplaced details in UV space. A new atlas requires rebaking associated texture maps and checking seams.
4. Keep facial morphs functional during sculpting. Follow [coherent endpoint transformations and attachment calibration](09-customization-and-hybrid.md) for lips, eyelids, teeth, eye pivots and the neck. Recheck smile, wide-open eyes, blink closure and jaw opening at extremes. Normalized landmark ratios can support review, but appearance acceptance comes from the rendered character.
5. Make the chosen outfit follow the new body. Refit and skin sleeves, waistband, knees, shoes and layered hems. Single-atlas recoloring suits a color-only request. Different neckline, garment cut or silhouette may need a new mesh, weights and UVs. Check asymmetric seams, logos, garment drape and shoe profile. Use [production garment and contact checks](11-full-body-production.md) after changing fit.

## Compare before final handoff

Use consistent lens, angle, pose, framing and light when comparing revisions. Capture neutral front, profile and three-quarter face, plus full-body front, side and rear when visible. Compare separately for likeness, clothing and deformation under motion. Ask for visual review of material uncertainties rather than claiming a literal match to unseen geometry. With an unavailable authoring tool or missing source, deliver usable rig/configuration progress and identify the remaining asset and view needed.
