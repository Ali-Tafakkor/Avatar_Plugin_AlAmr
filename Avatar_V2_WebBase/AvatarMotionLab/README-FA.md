# Avatar / Motion Lab

آزمایشگاه تحت وبِ حرکت کاراکتر و حالت‌های صورت، با Three.js و رابط فارسی.

## وضعیت این تحویل — ابتدا بخوانید

این بسته شامل **کد پروژه، محیط آزمایشی، راه‌انداز و آزمون‌ها** است. به دلیل محدودیت دریافت فایل باینری در محیط ساخت، **مدل GLB، کتابخانهٔ Three.js و دادهٔ انیمیشن داخل ZIP اولیه نیستند**. راه‌انداز آن‌ها را در اولین اجرا از نسخه‌های مشخص دریافت و داخل همین پوشه ذخیره می‌کند. پس از تکمیل دریافت، برای اجرای معمول به اینترنت یا API key نیاز نیست.

مدل انتخاب‌شده، نمونهٔ مردانهٔ AvatarSDK در پروژهٔ TalkingHead است؛ مدل اختصاصیِ مجسمه‌سازی‌شده برای این پروژه نیست. طبق توضیح منبع، این نمونه **برای استفادهٔ غیرتجاری** ساخته شده است. جزئیات در `THIRD_PARTY_NOTICES.md` آمده است.

منطق حرکت، پرش، برخورد، وزن‌های حالت‌های صورت، استخراج انیمیشن و سرور محلی آزموده شده است. **بارگذاری واقعی مدل، تطبیق نهایی اسکلت، ظاهر احساسات روی صورت و کیفیت بصری حرکت در این محیط قابل آزمون نبودند.** بنابراین این نسخه یک نمونهٔ توسعه‌ای است، نه تأیید کیفیت فوتورئال یا سینمایی. طبیعی‌بودن نهایی به کیفیت مدل، بافت‌ها و تطبیق اسکلت وابسته است.

## اجرا در ویندوز

### روش ساده

1. فایل ZIP را کامل Extract کن. برنامه را از داخل ZIP اجرا نکن.
2. وجود Node.js نسخهٔ ۲۲ یا بالاتر را بررسی کن. در PowerShell بنویس:

```powershell
node --version
```

در صورت نصب‌نبودن، Node.js را از وب‌سایت رسمی https://nodejs.org/ نصب کن و پنجرهٔ PowerShell را دوباره باز کن. نصب Node.js تنها پیش‌نیاز راه‌انداز است؛ نیازی به npm install، Blender، حساب AvatarSDK یا API key برای اجرای این نمونه نیست.

3. روی `START-WINDOWS.cmd` دوبار کلیک کن. پنجرهٔ سرور باید باز بماند. مرورگر به‌صورت خودکار باز می‌شود. در اجرای اول، پیشرفت دریافت فایل‌ها روی صفحه و در پنجرهٔ راه‌انداز نمایش داده می‌شود.

نشانی پیش‌فرض:

```text
http://127.0.0.1:4173
```

اگر این پورت اشغال باشد، سرور یکی از ده پورت بعدی را امتحان می‌کند؛ نشانی صحیح در پنجرهٔ راه‌انداز چاپ می‌شود. برای پایان کار، در همان پنجره Ctrl+C بزن.

### اجرای مستقیم در PowerShell

داخل پوشه‌ای که `start.mjs` قرار دارد:

```powershell
node start.mjs
```

یا، پس از تکمیل دریافت اولیه:

```powershell
node start.mjs --offline
```

گزینه‌های تکمیلی:

```powershell
node start.mjs --offline --no-open --port=4175
```

روی `index.html` دوبار کلیک نکن؛ بارگذاری فایل GLB و JavaScript module به سرور محلی نیاز دارد. هیچ فایل اجرایی ناشناس، نصب سراسری npm، تغییر رجیستری یا دسترسی Administrator لازم نیست.

## نخستین آزمایش

پروژه با نمای نزدیک صورت و لبخند آرام شروع می‌شود. با کلیدهای ۰ تا ۵ احساسات را تغییر بده. شدت را با اسلایدر کم و زیاد کن. با F به نمای صورت و با V به دوربین حرکت برو. فشردن کلید حرکت یا پرش هنگام نمای صورت، حالت دوربین را به سوم‌شخص تغییر می‌دهد.

| ورودی | عملکرد |
|---|---|
| W / A / S / D یا کلیدهای جهت‌نما | حرکت نسبت به جهت دوربین |
| نگه‌داشتن Shift همراه حرکت | دویدن |
| Space | پرش؛ با نگه‌داشتن کلید پرش پیاپی انجام نمی‌شود |
| 0 | صورت خنثی |
| 1 | لبخند آرام، حالت پیش‌فرض |
| 2 | خنده |
| 3 | ناراحتی |
| 4 | عصبانیت |
| 5 | تعجب |
| F | نمای نزدیک صورت |
| V | دوربین دنبال‌کنندهٔ سوم‌شخص |
| C | جابه‌جایی میان دوربین صورت، دنبال‌کننده و آزاد دور کاراکتر |
| کشیدن ماوس روی صحنه | چرخاندن دوربین |
| چرخ ماوس | نزدیک و دور کردن دوربین |
| B | یک بار پلک‌زدن |
| R | بازگشت به نقطه و حالت اولیه |
| H | پنهان/نمایان کردن پنل و کنترل‌های روی صفحه |

ورودی از `KeyboardEvent.code` استفاده می‌کند؛ جای فیزیکی کلیدهای WASD حتی با چیدمان فارسی مبنا قرار می‌گیرد. هنگامی که داخل اسلایدر یا فهرست انتخاب هستی، کلیدها برای همان کنترل حفظ می‌شوند؛ برای بازگشت به حرکت روی صحنه کلیک کن. این نسخه برای **دسکتاپ با ماوس و صفحه‌کلید** است؛ نمایش کوچک صفحه پشتیبانی می‌شود اما جوی‌استیک لمسی ندارد.

## امکانات پیاده‌سازی‌شده

### صورت

شش حالت صورت با ترکیب چند morph target واقعی؛ گذار تدریجی به‌جای تعویض ناگهانی. پلک‌زدن، حرکت محدود نگاه به دوربین، حرکت ظریف چشم و تغییر خفیف فک هنگام خنده نیز پیاده‌سازی شده‌اند. حالت‌های دستی برای بازشدن فک، لبخند، افتادگی لب، بالا/پایین رفتن ابرو و بازشدن چشم در پنل وجود دارد. شدت حالت، حرکت‌های ظریف و نگاه قابل کنترل‌اند.

این‌ها حرکت هندسهٔ صورت هستند، نه تصویر دوبعدی، ایموجی یا تعویض بافت. بااین‌حال اجرای هر کانال به وجود همان morph در GLB بستگی دارد. شمار کانال‌های واقعی پس از بارگذاری نمایش داده می‌شود؛ نبود کانال‌های ضروری با پیام هشدار و Console گزارش می‌شود. عدد ثابتی برای تعداد کانال‌ها، وضوح بافت یا تعداد رأس‌های مدل ادعا نشده است.

### حرکت و بدن

حرکت دارای شتاب‌گیری، کاهش سرعت، چرخش تدریجی بدن و برخورد با دیوار و موانع است. انیمیشن‌های idle / walk / run از نمونهٔ Xbot در Three.js گرفته و روی اسکلت کاراکتر تطبیق داده می‌شوند. سرعت فاز راه‌رفتن به جابه‌جایی واقعی متصل است؛ پشت مانع، ورودی حرکت به‌تنهایی باعث ادامهٔ راه‌رفتن نمی‌شود.

پرش شامل آماده‌سازی کوتاه، حرکت بالستیک، جمع‌شدن اندام‌ها در هوا و فشردگی هنگام فرود است. **این بخش به‌صورت procedural نوشته شده، نه موشن‌کپچر پرش.** تنظیم دو استخوان پا برای تماس با زمین و کاهش لغزش پا، تنفس خفیف و کمی خم‌شدن بدن هنگام تغییر مسیر نیز وجود دارد. این‌ها روش‌های تقریبی برای طبیعی‌ترشدن حرکت هستند؛ جایگزین موشن‌کپچر اختصاصی، فیزیک کامل بدن، motion matching یا حل‌گر حرفه‌ای تماس پا نیستند.

### دوربین و محیط

سه دوربین: نمای نزدیکِ قابل چرخش صورت، نمای آزاد دور بدن و سوم‌شخص دنبال‌کننده. دوربین سوم‌شخص با حرکت نرم دنبال می‌کند؛ میدان دید هنگام دویدن کمی بازتر می‌شود. فاصله با مانع بررسی می‌شود تا دوربین کمتر از دیوار عبور کند. با تغییر حالت، انتقال دوربین تدریجی است.

محیط، حیاط سادهٔ آزمایش با کف علامت‌گذاری‌شده، موانع، نیمکت، گیاه و سکوهای مختلف است. نورپردازی روز، استودیو و عصر؛ سایه؛ سه سطح کیفیت؛ حرکت آهسته؛ نمایش اسکلت و نمایش شبکهٔ مدل در پنل وجود دارد. دکمهٔ تصویر، نمای سه‌بعدی همان لحظه را به PNG ذخیره می‌کند؛ ضبط ویدئو یا تولید صدا در این نسخه وجود ندارد.

## فایل‌های دریافت‌شونده و اجرای آفلاین

| فایل | نقش |
|---|---|
| `assets/avatar.glb` | مدل نمونهٔ مردانه، اسکلت و بافت‌های تعبیه‌شده |
| `assets/motions.json` | فقط اسکلت مرجع و دادهٔ سه انیمیشن استخراج‌شده؛ بدون مدل Xbot |
| `assets/provenance.json` | نسخه‌ها، هش‌ها، نشانی منبع و حجم واقعی فایل‌های دریافت‌شده |
| `vendor/` | نسخهٔ محلی Three.js 0.180.0، بارگذارها و decoder لازم |

مدل اصلی در منبع ۱۲٬۲۸۴٬۰۴۰ بایت است. اندازهٔ نهاییِ همهٔ وابستگی‌ها اینجا اندازه‌گیری نشده؛ مقدار واقعی پس از راه‌اندازی در `runtimeBytes` در `assets/provenance.json` ثبت می‌شود. راه‌انداز مدل Xbot را موقتاً برای استخراج حرکت دریافت و سپس فایل موقت آن را حذف می‌کند. در صورت نیاز مدل به Draco، فایل decoder هم دریافت می‌شود.

برای انتقال به دستگاه آفلاین، بعد از یک راه‌اندازی موفق، **کل پوشهٔ پروژه شامل assets و vendor** را کپی یا ZIP کن. روی دستگاه دوم فقط Node.js و مرورگر سازگار لازم است. برای ساخت نسخهٔ آفلاین در PowerShell از پوشهٔ والد:

```powershell
Compress-Archive -Path .\AvatarMotionLab -DestinationPath .\AvatarMotionLab-Offline.zip
```

این انتقال برای همان استفادهٔ غیرتجاری است؛ محدودیت مجوز مدل با ZIP کردن آن تغییر نمی‌کند.

## رفع خطا

**Node شناخته نمی‌شود:** پس از نصب Node.js، پنجرهٔ ترمینال را ببند و دوباره باز کن؛ `node --version` باید عددی از ۲۲ به بالا برگرداند.

**دریافت مدل یا کتابخانه متوقف می‌شود:** اتصال به GitHub Raw و CDNهای معرفی‌شده در `tools/setup.mjs` را بررسی کن. راه‌انداز چند منبع را امتحان می‌کند و فایل سالمِ قبلی را نگه می‌دارد. پس از رفع مشکل، پنجرهٔ راه‌انداز را ببند و دوباره اجرا کن. دکمهٔ داخل صفحه فقط وضعیت را دوباره می‌خواند، نه اینکه فرآیند ناموفق دانلود را از ابتدا اجرا کند. دانلود روی سرور محلی انجام می‌شود؛ در صورت لزوم باید پراکسی معتبر سیستم یا `HTTPS_PROXY` برای curl قابل استفاده باشد. بررسی TLS یا checksum را غیرفعال نکن.

**خطای checksum:** فایل با نسخهٔ مشخص‌شده مطابق نیست. فایل معیوب را از پوشهٔ assets حذف کن و از منبع اصلی دوباره بگیر؛ هش داخل کد را صرفاً برای ساکت‌کردن خطا تغییر نده.

**WebGL 2 شروع نمی‌شود یا تصویر سیاه است:** شتاب سخت‌افزاری مرورگر و درایور گرافیک را بررسی کن. در Chrome یا Edge امتحان کن. اگر مدل بارگذاری شد اما سرعت پایین بود، کیفیت را روی «سبک» بگذار. نرخ فریم روی سخت‌افزار کاربر اندازه‌گیری نشده است.

**صورت یا بدن بدشکل می‌شود:** با 0 صورت را خنثی کن، R را بزن و حالت اسکلت را بررسی کن. پیش از نتیجه‌گیری دربارهٔ انیمیشن، نام‌های استخوان، جهت رو به جلو، وضعیت bind pose و morphهای مدل را بررسی کن. تطبیق مدل در این محیط بصری آزمایش نشده است. فایل `src/animation.mjs` نقطهٔ اصلی اصلاح تطبیق و `src/expressions.mjs` محل اصلاح وزن‌های صورت است.

## ساختار کد و توسعه

```text
index.html / style.css    رابط فارسی و چیدمان
boot.js                  وضعیت راه‌اندازی و شروع برنامه
start.mjs                سرور محلی و اجرای راه‌انداز
src/main.mjs             اتصال اجزا و حلقهٔ رندر
src/actor.mjs            بارگذاری، اندازه و شناسایی اسکلت/صورت
src/animation.mjs        تطبیق idle/walk/run، پرش و تماس پا
src/expressions.mjs      ترکیب احساس‌ها، پلک و نگاه
src/physics.mjs          حرکت، گرانش و برخورد
src/camera.mjs           سه حالت دوربین

 docs/                   گزارش آزمون و چک‌لیست پذیرش
```

برای آزمون منطق کد، بدون دانلود مدل:

```powershell
node --test
```

سرور فقط روی `127.0.0.1` گوش می‌دهد و برای انتشار عمومی روی اینترنت طراحی نشده است. برنامه، تصویر، صدا و دادهٔ شخصی به API ارسال نمی‌کند. تنها درخواست‌های بیرونیِ تعریف‌شده مربوط به دریافت وابستگی‌ها در راه‌اندازی اولیه‌اند.

برای استفاده از مدل دیگری، سازگاری اسکلت و نام morphها باید بررسی شود؛ جایگزینی هر GLB دلخواه تضمین‌شده نیست. حفاظت checksum راه‌انداز برای نمونهٔ مشخص‌شده است؛ واردکردن مدل شخصی به مسیر جداگانه و تغییر بارگذار نیاز دارد، نه تغییر بی‌دلیل هش منبع. چک‌لیست عملی در `docs/TEST_REPORT.md` آمده است.
